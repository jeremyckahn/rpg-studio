# RPG Studio

**RPG Studio** is a free, open-source, browser-based tool for making classic top-down RPGs, in the spirit of RPG Maker. You paint maps, fill in a game database, script events, draw sprites, and export a game that runs in any modern browser. Everything runs in your browser; there is nothing to install and no account to create.

**Open the app:** <https://rpg-studio.com> · **Source code:** <https://github.com/jeremyckahn/rpg-studio>

RPG Studio is also built to be driven by AI agents: a local "companion bridge" lets an agent read and edit your project while you watch, and every change it makes can be undone in one step. See [AI Companion](ai-companion.md).
